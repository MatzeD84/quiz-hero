# Helden als Belohnung

Stand: 31.10.2026 · veröffentlicht.

Spieler können zusätzliche Helden durch richtige Antworten verdienen. Eine Freischaltung macht den Helden dauerhaft auswählbar, wechselt aber nicht automatisch das aktuelle Profilbild. Die Bedingungen sollen abwechslungsreich sein und sich im Admin ohne Programmierung einstellen lassen.

## Eine Belohnung einrichten

1. Bei Bedarf unter **Mediathek → Profilbilder** ein Bild hochladen.
2. Unter **Helden** Name und Fähigkeiten pflegen, den Helden aktivieren und seine Verfügbarkeit auf **Belohnung** stellen.
3. Unter **Belohnungen → Neue Helden** eine Regel anlegen oder die bestehende bearbeiten. Pro Held gibt es eine Regel. Der Editor fasst die Auswahl als lesbaren Satz zusammen.

| Einstellung | Auswahl |
|---|---|
| Richtige Fragen | 1 bis 10.000 unterschiedliche Fragen |
| Schwierigkeit | Alle, einfach, schwer oder Hero |
| Versuch | Nur erster oder erster und zweiter |
| Hilfe | Ohne Heldenfähigkeit oder Hilfe erlaubt |
| Kategorie | Alle oder eine bestimmte Kategorie |
| Zeitraum | Insgesamt über mehrere Runden oder innerhalb einer einzigen Questrunde |
| Status | Entwurf, aktiv oder archiviert |

Eine Einzelrundenregel muss mit der gewählten Rundengröße und den verfügbaren Fragen erreichbar sein. Der Baukasten ändert die Fragenverteilung nicht.

## Was genau zählt?

Es zählen unterschiedliche, richtig beantwortete Fragen aus erfolgreich gespeicherten Runden, einschließlich Übungsrunden. Dieselbe Frage mehrfach zu lösen erhöht den Fortschritt nicht erneut. Falsche Antworten, Trostpunkte und übersprungene Fragen zählen nicht.

**Insgesamt** sammelt passende Fragen über mehrere Runden. **In einer Questrunde** verlangt die gesamte Leistung in einer einzigen Runde; kleinere Teilerfolge werden nicht addiert. „Ohne Hilfe“ gilt je Frage: Hilfe bei einer anderen Frage schadet nicht.

Auch belegbare frühere Antworten können beim nächsten Rundenabschluss oder Sammlungsabgleich berücksichtigt werden. Das Aktivieren einer Regel allein vergibt noch nicht sofort an alle Accounts. Änderungen oder Archivierung entziehen keine bereits verdienten Helden. Bei der Vergabe werden die damaligen Bedingungen festgehalten, damit spätere Änderungen den Freischaltgrund nicht verfälschen.

## Eingestellte Beispiele bei Veröffentlichung

| Held | Bedingung |
|---|---|
| Astra | Eine Hero-Frage im ersten Versuch ohne Hilfe richtig beantworten. |
| Akuma | Insgesamt zwei unterschiedliche Hero-Fragen im ersten Versuch ohne Hilfe richtig beantworten. |
| Amphos | Insgesamt fünf unterschiedliche Fragen richtig beantworten; beide Versuche und Hilfe erlaubt. |
| Cassius | Drei unterschiedliche Fragen in einer Questrunde ohne Hilfe richtig beantworten; beide Versuche erlaubt. |
| Horus | Insgesamt fünf unterschiedliche Rom-Fragen ohne Hilfe richtig beantworten; beide Versuche erlaubt. |

Diese Regeln sind veränderbar. Winterseherin ist als Belohnungsheld markiert, hat aber noch keine aktive Vergaberegel und wird deshalb nicht automatisch freigeschaltet. Es gibt keine zusätzlichen sichtbaren Testduplikate der Helden.

## Anzeige für Spieler

Das Quiz-Ergebnis zeigt Bild, Namen und eine kurze Begründung der neuen Freischaltung. Von dort führt ein Link zur Heldenauswahl im Konto. Auf der Souvenir-Seite erscheinen nur bereits verdiente Helden; in der Kontoauswahl tragen sie das Tag **Belohnung**.

Ein deaktivierter Held wird nicht angeboten. Verwendet ihn ein Account gerade, greift der Standardheld als Ersatz. Die verdiente Berechtigung bleibt dabei erhalten.

## Bewusste Grenzen

Noch keine freien UND-/ODER-Regelgruppen, Zeitlimits oder manuelle Einzelvergaben. Gesperrte Belohnungshelden werden Spielern nicht als vollständiger Katalog vorab gezeigt.
